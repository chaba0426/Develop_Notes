# 部屋・ラン・ショップ仕様

状態: ループと抽選/更新ルールは**確定**。数値・演出・UIデザインは**仮/未決定**。

## RUN-001: 部屋構造【確定/仮】

- 少数の手作りアリーナをランダムに選び、繰り返し利用する。中央は開け、基本は平坦または緩やかな起伏。
- アリーナ数は最初1部屋、拡張後1〜3種類程度を想定（**仮**）。
- 1ランは通常部屋を進み最終ボスへ。**通常5部屋＋ボス1部屋は仮置き**。
- 部屋クリア後にショップを表示し、購入等を終えて次の部屋へ移る。次の部屋のロード中にショップUIを見せる案もあり、実装方式は未決定。
- プレイヤーのHPが0になったらラン失敗。

## ROOM-001: クリア条件【確定】

| 条件 | クリアのタイミング |
| --- | --- |
| N体討伐 | 累計討伐数がNに達したとき |
| N秒生存 | 規定時間を生き延びたとき |

- **どちらも敵全滅を待たずにクリア**。クリア条件達成後は共通の終了処理。
- 生存型でも敵を倒すほど通貨が得られるので、逃げ続けるより戦う誘因がある。
- 「制限時間内にN体討伐」は当面入れない（失敗条件・調整が増えるため）。
- Nの値、部屋種別ごとの配分は未決定。

## SPAWN-001: 継続増援【確定】

- 敵の残数0を待たず、撃破数などに応じて増援を出し続ける。
- ウェーブは主に出現ペース・構成の内部単位。部屋内の戦闘を途切れさせない。
- 同時存在数に上限を設定する。上限値・補充速度・スポーン配置は未決定。

## ECON-001: 通貨【確定】

- 敵の撃破時、ラン内通貨を**自動加算**。拾い集める必要はない。
- 基本強化、特殊スキル、手動リロールの支払いは同じ通貨。
- 通貨獲得量・初期価格・強化価格の伸び方は未決定。

## SHOP-001: 商品と更新【確定】

- **常に3枠**。各枠が独立に「基本強化」か「特殊スキル（またはそのレベルアップ）」を抽選。
- 基本強化: 攻撃力、HP、回復など通常のステータス系。
- 特殊: 行動や攻撃に効果を追加するスキル。取得済みの特殊スキルは、以後の特殊枠で**レベルアップ候補**にもなる。
- 所持通貨で買える限り、同じショップ内で何度でも購入できる。
- **どれか1商品を購入すると、3枠すべてを無料で再抽選**。残りの2商品も入れ替わる。
- **手動リロール**は通貨を消費して3枠すべてを再抽選。価格は同じショップで使うほど上昇。
- 手動リロール価格は**新しい部屋クリア後のショップへ入るたびにリセット**。同じショップを開き直して価格をリセットする想定ではない。
- 購入による無料再抽選は手動リロールとは別の操作。増額への影響など実装上の細部は未決定。

## UIイメージ【配置は仮】

```text
ROOM CLEAR / UPGRADE            所持通貨
┌─────────┬─────────┬─────────┐
│ 基本強化  │ 特殊スキル │ 基本強化  │
│ 名前/効果 │ 名前/効果  │ 名前/効果 │
│ 価格/購入 │ 価格/購入  │ 価格/購入 │
└─────────┴─────────┴─────────┘
           [全3枠を有料リロール]
           [次の部屋へ進む]
```

HTMLのショップ画面にある具体的な商品名・金額・アイコンは**ダミー**。購入UIはデザイン資料であり、機能する試作品ではない。
