# リア 攻撃モーション — 撮影用チェックシート

[詳細仕様](AttackMotion_WeakWeakStrong.md) ｜ **撮影中に見るための短縮版**

**右手に剣。左右は自分から見た方向。** まずは**弱1→弱2→強3を通しで**自然な速度で演じる。秒数は合わせなくてOK。

## 弱1（目安0.4秒）
- **右足を半歩前へ**出しながら斬る。
- **右胸〜右脇 → 左腰**：右上→左下の**浅い斜め斬り**（20〜30°）。
- コンパクトに**素早く振り抜く**。大きく振りかぶらない。
- **終わり：剣は左腰、剣先は左下。**

## 弱2（目安0.4秒）
- **足は踏み足さない**。弱1の終わりからそのまま切り返す。
- **左下→右上**へ約45°の斬り上げ。
- **終わり：剣は右肩〜頭の横。** 頭上まで上げない。

## 強3（目安0.65秒・仮）
- **左足を踏み込み、少し沈んで溜める。**
- **低く跳んで反時計回りに360°**（上から見た回転方向）。
- **空中で約270° → 着地しながら残り90°**。回転中から斬る。
- **左側へ沈み込みながら左下へ振り抜く。**
- **終わり：左膝を曲げ、右脚を横へ伸ばす低いサイドランジ。正面を向く。**

## 撮る前の最終確認
- [ ] **右足 → 足はそのまま → 左足**の流れ
- [ ] **右上→左下 → 左下→右上 → 回転して左下**
- [ ] 強3は**高く跳ばない**。着地と最後の斬撃をつなげる
- [ ] 秒数や細かい手首・剣先の動きは気にしすぎない。**自然さ優先**
- [ ] 全身・足先が映る位置で撮る。安全な小道具、周囲のスペースと床を確認

**あとで調整:** 段ごとに切り出し、Blenderで開始/終端・速度・接地・剣の軌道を修正。
