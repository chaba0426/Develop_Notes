# リア（Leir）攻撃モーション仕様 — 弱1 → 弱2 → 強3

状態: **モーション設計の現行案**（2026-11-01）。方向・足運び・終端姿勢は今回合意した方針。時間配分と細部は**仮**で、撮影・Blender調整・プレイテストで変更してよい。

撮影時に見る短縮版: [AttackMotion_ShootingChecklist.md](AttackMotion_ShootingChecklist.md)  
戦闘全体のルール: [Combat.md](Combat.md)

## 1. 目的と前提

- 主人公リア: 7〜8頭身、金髪ボブ・青い瞳、女性寄りの中性的な若い冒険者。右手に片手直剣、左腕は姿勢のバランスを取る。
- 目指す手触り: **弱攻撃は軽快で鋭く、強3は回転の勢いと着地の重さで締める**。斬撃の急加速・急減速を重視する。
- 実際の攻撃判定の広さはゲームロジックとエフェクトで補える。**剣の見た目の軌道を無理に広げない**。
- モーションは1段ずつクリップ化してゲーム内でブレンドする。連続撮影した素材から段ごとに切り出してよい。
- FBXで自作エンジンへ取り込む想定。**Root Motionによる移動制御は使わず**、前進・ジャンプ移動などの実移動量はゲーム側で制御する。
- 方向の記述は**キャラクター本人から見た右／左**。正面から撮影した映像では左右が鏡像になる。
- 回転の「反時計回り」は**上から見たとき**の方向。
- ここでの秒数はモーションの設計目安。ゲームの判定発生・キャンセル受付・硬直は [Combat.md](Combat.md) と実装側で管理する。秒数を撮影中に厳密再現する必要はない。

## 2. コンボ全体

| 段 | 目安尺 | 基本動作 | 足運び | 終端 |
| --- | --- | --- | --- | --- |
| 弱1 | 0.40秒 | 右上→左下の浅い斜め斬り（20〜30°） | **右足を半歩前へ**。踏み込みと斬撃を重ねる | 剣は左腰付近・剣先は左下 |
| 弱2 | 0.40秒 | 左下→右上の斜め斬り上げ（約45°） | **追加の踏み込みなし** | 剣は右肩〜頭の横。頭上まで上げすぎない |
| 強3（弱弱強の3段目） | 0.65秒（仮） | 低い跳躍を伴う反時計回り360°回転斬り | **左足踏み込み**→低く跳躍→着地 | 左膝を曲げ、右脚を横へ伸ばす低いサイドランジ。剣は左下 |

**連結の考え方:** 弱1で左下へ振り抜いた剣を弱2で右上へ返す。弱2で右肩〜頭の横にある剣を強3の溜めへ利用する。開始・終了姿勢はブレンドを前提に調整する。

## 3. 弱1 — コンパクトな斜め斬り

### 動作

1. 右胸〜右脇付近に剣を置く中段の構え。右肘は軽く曲げ、剣を大きく引かない。
2. **右足を小さく前に出すのと同時に**、腰→肩→右腕を連動させて振り始める。
3. 本人基準で**右上→左下**へ20〜30°程度の浅い斜め斬り。大きく身体を回さず、鋭く加速して振り抜く。
4. 右足の着地と斬撃の終わりをおおむね重ねる。
5. 剣は**左腰付近、剣先は左下**へ。勢いを吸収し、弱2でそのまま斬り返せる位置に残す。

### 仮タイムライン（合計0.40秒）

| 時間 | 意図 |
| --- | --- |
| 0.00〜0.06秒 | 右足を出し始め、重心移動・腰と肩の回転を開始 |
| 0.06〜0.18秒 | 斬撃の主区間。急加速して右上→左下へ |
| 0.18〜0.25秒 | 着地・振り抜き・減速 |
| 0.25〜0.40秒 | 弱2へつながる位置に収める（長い静止は不要） |

### 避けたい動き

- 斬る前に剣を左側へ持っていく、大きく右へ引き直すなどの余計な予備動作。
- 弱攻撃とは思えない大きな全身回転や、等速でゆっくりした斬撃。
- 攻撃範囲を広げるためだけに腕を無理に伸ばしきる動き。

## 4. 弱2 — 斜め斬り上げ

### 動作

1. **弱1の終端（剣が左腰・左下）から直接開始**する。
2. 足を新たに踏み出さず、腰・肩の回転を切り返しながら、本人基準で**左下→右上**へ約45°の斬り上げ。
3. 腰・肩・右腕を連動させ、上体を軽く起こす。弱1より上方向への動きを明確にして、敵を浮かせる印象につなげる。
4. **剣は右肩〜頭の横で止める**。大きく頭上へ振り上げない。
5. この終端を強3の溜め開始姿勢に利用する。

### 演出・調整

- 目安尺は**0.40秒**。弱1と同様に斬撃の急加速・急減速を優先するが、細かい時間内訳は未固定。
- 弱1の完全な逆再生に見えないよう、身体の切り返し・剣の高さ・斬り上げ角度に差をつける。
- 足元が不自然に捻れないよう、腰の回転と足先の向きを撮影後に確認する。

## 5. 強3 — 低い跳躍360°回転斬り

### 動作

1. 弱2の終端で剣が右肩〜頭の横にある状態から、剣を**右肩後方へ軽く引き**、身体を沈めて溜める。
2. **左足を前へ踏み込み**、地面を蹴って**低く跳躍**。高く跳ぶのではなく、両足が短く浮く程度の低空回転。
3. **上から見て反時計回り**に360°回転。剣を身体の外側へ広げながら周囲を薙ぐ。最初から腕を伸ばしきる必要はなく、回転の中で自然に振り抜く。
4. **約270°は空中**で回り、着地しながら**残り約90°**を斬る。角度は動きの目安で、厳密に演じる必要はない。
5. 着地に合わせて重心を左へ沈め、**左膝を曲げ・右脚を横へ伸ばすサイドランジ**へ。右膝は伸ばしきらず余裕を残す。
6. 剣を**胸〜腰の高さから左下**へ振り抜き、最後は**正面を向いた低い姿勢**で終える。

### 仮タイムライン（合計0.65秒）

| 時間 | 意図 |
| --- | --- |
| 0.00〜0.25秒 | 左足を踏み込み、沈み込み・剣を右肩後方へ引いて溜める |
| 0.25〜0.32秒 | 低く蹴り出し、回転開始 |
| 0.32〜0.52秒 | 空中で約270°回転しながら斬る |
| 0.52〜0.65秒 | 着地・沈み込みとともに残り約90°を斬り、左下へフィニッシュ |

- **斬撃は空中回転中から始める**。着地してからだけ斬る動作にはしない。
- 接地した足を固定して強引に360°捻らない。足先や接地タイミングは自然な範囲で調整する。
- 強3終了後の**後隙0.35秒はゲームロジック側**で管理し、アニメーション終了後はIdleへブレンドする方針。
- 尺0.65秒はかなり速い想定。撮影・調整で無理が出れば**0.70〜0.80秒程度への変更も検討可能**。現段階では仮のまま。

## 6. 撮影・モーション化・編集方針

1. **最初は弱1→弱2→強3を通しで演じる**と、重心と足運びのつながりを作りやすい。必要なら各段を単独でも撮る。
2. **撮影中は秒数に無理に合わせない**。斬撃方向・足運び・大まかな溜めと加速を守り、自然に動ける速さで撮影する。
3. 取得した動画から各段をトリミングし、動きの再現に使う。**実写→Viggle直接**と**実写→Muse→Viggle**の品質・対応機能は未検証なので、後で小さく比較する。
4. 抽出したモーションはBlenderで**姿勢、開始・終端、リタイミング、速度カーブ、剣の軌道、接地**を補正する。映像を先にリタイミングする方式も比較候補。
5. 各段をFBXとして出力し、ゲーム内でブレンドする。前進や移動量はアニメーション内のRoot Motionに頼らず、ゲーム側で別途制御する。
6. 撮影で剣状の小道具を使う場合は**柔らかく軽い安全なもの**を使用し、低い跳躍・回転は広く滑りにくい場所で無理なく実施する。

- 連結ブレンドの長さ、キャンセル時の姿勢補正、アニメーション速度制御ツールの有無。
