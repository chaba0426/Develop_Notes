## ENEMY-001: 基本雑魚 — 魔法生物【方針確定／ビジュアル仮ロック】

- 魔力が凝縮され、意思を持った下級魔物。人間・獣・機械のどれでもなく、大量発生する。
- **本体1パーツ＋浮遊する左右の爪2パーツ**。足と口はなく、目で敵意を伝える。Transformアニメーションを想定する。
- 形状、配色、通常／侵食個体の違い、画像資料の正本は [Characters.md](Characters.md)。
- 雑魚戦は多数の敵へ飛び込み、**集敵→吹き飛ばし→衝突**で大量撃破する遊びを優先する。
- まずこの1種類だけ実装する。基本攻撃は**片爪の打ち出し1種類**に絞り、リーチ・HP・速度・具体的な時間は実機で調整する。

## ENEMY-010: スポーン群と認識【方針確定】

- スポーンごとに**中心位置・範囲・指定数**を持ち、範囲内のランダム位置に敵を配置する。指定数は部屋ごとの設定値とする。
- スポーン単位の所属（SpawnGroup）は、その敵が存在する間保持する。
- プレイヤーが近づけば認識して接近・交戦し、十分離れれば撤退する。
- 具体的な認識／撤退距離、撤退時の戻り先は未決定。認識・撤退の境界にヒステリシスを設ける案は調整候補。

## ENEMY-011: CombatGroupと群衆行動【方針確定】

- 認識中の敵は、SpawnGroupをまたいで**常に1つのCombatGroupへ統合**する。元のSpawnGroup所属は変えない。
- CombatGroupが攻撃役の選出、威嚇など群衆行動をまとめて制御する。個体ごとの移動・モーション・被弾は敵側で処理する。
- 敵はプレイヤーへ**直接接近**。意図的な回り込みや包囲位置の確保は行わず、プレイヤーの位置取り・吹き飛び・密集によって自然に包囲が生じるようにする。
- **プレイヤー周辺の密度**が上がると同時攻撃枠と攻撃開始頻度を増やすが、両方に上限を設ける。
- 攻撃開始の間隔は**ランダム化**し、一斉に攻撃開始→終了→再攻撃する同期を防ぐ。
- 攻撃しない個体は移動・待機・威嚇を行う。密度の参照範囲、同時攻撃数、抽選方式、頻度・間隔の数値は未決定。
- **実装方針（仮）**: CombatGroupの動的所属はSparse管理。高頻度のTransform・移動・群衆衝突はArchetype側でまとめる。具体的な内部構造は検証する。

## ENEMY-012: 衝突判定【方針確定】

- **足元の接地用判定**と**敵同士の重なり解消用スフィア**を分ける。
- 群衆スフィアの半径は敵の状態で可変。集敵・吹き飛び・ダウンでは密集を許容できるようにする。
- スフィア同士の押し出し強度や半径復帰の補間は実機で調整。完全な分離より、リアの攻撃の当てやすさを優先する。
- 大量の敵で全ペア総当たりにならないよう、空間分割などの近傍検索方式を検討する。
- **吹き飛び中の敵のスフィア vs ほかの敵の群衆スフィア**を使って衝突を判定する。群衆の重なり解消とダメージ処理は役割を分離する。

## ENEMY-015: 雑魚敵の共通State【構成確定】

| State | 役割 |
| --- | --- |
| `Idle` | 非戦闘時の待機 |
| `Move` | プレイヤーへの接近・距離調整・撤退 |
| `Threaten` | プレイヤーに対する威嚇・攻撃待機 |
| `Attack` | 攻撃の実行（予兆・攻撃・後隙は内部フェーズ） |
| `Stagger` | 軽い怯み・ノックバック |
| `Launch` | 吹き飛び・空中に浮く状態 |
| `Down` | ダウン・復帰 |
| `Dead` | 死亡・消滅 |

- **基本雑魚だけでなく、今後の強い雑魚にも共通する8状態**を基本構成とする。敵ごとの特殊行動が必要になった場合に拡張する。
- **威嚇と攻撃予兆は別物**。攻撃許可を待つ行動が `Threaten`、爪を引くなどの予兆は `Attack` 内部で処理する。
- 代表的な流れは `Idle → Move → Threaten → Attack → Threaten`。攻撃後に距離が離れていれば `Move` に戻る。実際の遷移条件と割り込み優先度は実装時に検証する。
- プレイヤーの認識状態、CombatGroupへの所属・攻撃開始許可は、共通State自体とは**別に管理**する。
- 被弾の効き方は敵の種類・攻撃に応じて拡張可能にするが、**強い雑魚のSA（スーパーアーマー）や具体的な被弾耐性は未決定**。強い雑魚の内容を設計するときに検討する。
- 共通Stateはモーション方式と独立させる。今回の魔法生物は本体・左右爪の**Transformをコード制御**し、別の敵がアニメーションファイルを使っても共通Stateは利用できるようにする。

## ENEMY-016: 基本雑魚の片爪攻撃【挙動確定／数値調整】

- **攻撃は1種類**。左右いずれかの浮遊する爪を**攻撃開始時にランダム選択**し、その攻撃中は切り替えない。
- **予兆**：選択された爪を本体の後方へ短く引く。予兆中はプレイヤーに向きを合わせる。
- **攻撃**：爪を前方に素早く打ち出し、**打ち出し開始時に攻撃方向を固定**。本体はほぼその場に留まる。
- **後隙**：爪が前へ出た状態から通常の浮遊位置へ戻る。後隙中も攻撃開始には戻らない。
- アニメーションファイルを前提とせず、爪のTransform・補間カーブを**コードで制御**する。左右で同じ挙動を反転して使う。
- 攻撃判定は爪の軌道に沿ったスフィア等を想定し、ゲーム上の攻撃フェーズと見た目の補間を分離する。
- **予兆・攻撃・後隙の時間、リーチ、スフィア半径、追尾旋回速度は実機調整**。短い予兆を基本とし、長い溜めは要求しない。
- 魔力を使う追加攻撃は**初期の基本雑魚には設けない**。将来の敵種などで必要になった際に別途検討する。
