# 敵・ボス仕様

状態: 基本雑魚の行動・群衆制御とリアクションの**方向性は確定**。具体的な数値・攻撃モーション・HP等は**未決定**。

## ENEMY-001: 基本雑魚 — 魔法生物【方針確定／ビジュアル仮ロック】

- 魔力が凝縮され、意思を持った下級魔物。人間・獣・機械のどれでもなく、大量発生する。
- **本体1パーツ＋浮遊する左右の爪2パーツ**。足と口はなく、目で敵意を伝える。Transformアニメーションを想定する。
- 形状、配色、通常／侵食個体の違い、画像資料の正本は [Characters.md](Characters.md)。
- 雑魚戦は多数の敵へ飛び込み、**集敵→吹き飛ばし→衝突**で大量撃破する遊びを優先する。
- まずこの1種類だけ実装する。個別攻撃の種類・範囲・HP・速度・数値は未決定。

## ENEMY-010: スポーン群と認識【方針確定】

- スポーンごとに**中心位置・範囲・指定数**を持ち、範囲内のランダム位置に敵を配置する。指定数は部屋ごとの設定値とする。
- スポーン単位の所属（SpawnGroup）は、その敵が存在する間保持する。
- プレイヤーが近づけば認識して接近・交戦し、十分離れれば撤退する。
- 具体的な認識／撤退距離、撤退時の戻り先は未決定。認識・撤退の境界にヒステリシスを設ける案は調整候補。

## ENEMY-011: CombatGroupと群衆行動【方針確定】

- 認識中の敵は、SpawnGroupをまたいで**常に1つのCombatGroupへ統合**する。元のSpawnGroup所属は変えない。
- CombatGroupが攻撃役の選出、威嚇など群衆行動をまとめて制御する。個体ごとの移動・モーション・被弾は敵側で処理する。
- 敵はプレイヤーへ**直接接近**。意図的な回り込みや包囲位置の確保は行わず、プレイヤーの位置取り・吹き飛び・密集によって自然に包囲が生じるようにする。
- **プレイヤー周辺の密度**が上がると同時攻撃枠と攻撃開始頻度を増やすが、両方に上限を設ける。
- 攻撃開始の間隔は**ランダム化**し、一斉に攻撃開始→終了→再攻撃する同期を防ぐ。
- 攻撃しない個体は移動・待機・威嚇を行う。密度の参照範囲、同時攻撃数、抽選方式、頻度・間隔の数値は未決定。
- **実装方針（仮）**: CombatGroupの動的所属はSparse管理。高頻度のTransform・移動・群衆衝突はArchetype側でまとめる。具体的な内部構造は検証する。

## ENEMY-012: 衝突判定【方針確定】

- **足元の接地用判定**と**敵同士の重なり解消用スフィア**を分ける。
- 群衆スフィアの半径は敵の状態で可変。集敵・吹き飛び・ダウンでは密集を許容できるようにする。
- スフィア同士の押し出し強度や半径復帰の補間は実機で調整。完全な分離より、リアの攻撃の当てやすさを優先する。
- 大量の敵で全ペア総当たりにならないよう、空間分割などの近傍検索方式を検討する。
- **吹き飛び中の敵のスフィア vs ほかの敵の群衆スフィア**を使って衝突を判定する。群衆の重なり解消とダメージ処理は役割を分離する。

## ENEMY-013: 被弾・吹き飛び【方針確定】

| 攻撃・状況 | リアクション |
| --- | --- |
| 弱1 | **軽ノックバック**で集敵 |
| 弱2 | **宙に浮く吹き飛び**で集敵 |
| 強攻撃系 | 吹き飛び |
| 吹き飛び終了・着地後 | ダウンへ移行 |
| ダウン中 | **追撃可能（攻撃が当たる）** |
| 吹き飛んだ敵との衝突 | **ダメージ＋短いヒットストップ**。衝突された側のモーションは軽ノックバックと同じ |

- **敵の大分類ごとに**軽ノックバック／吹き飛び／ダウンの効き方を変更できる方針。
- 弱2で浮かせた敵を次の強攻撃で巻き込めることを優先。浮遊時間・当たり判定の高さ・飛距離・数値は未決定。
- 吹き飛び衝突の連続ヒット防止・連鎖の有無・ダメージ倍率は未決定。
- 衝突ダメージを伸ばすなどの**吹き飛ばしビルド**へ拡張できる構造を目指す。

## BOSS-001: 初期ボス【確定／仮】

- 初期状態は**1対1**、**HPを0にすれば勝利**。体勢ゲージ・スタンは未搭載。
- 攻撃に明確な予兆を設け、攻撃後に**短い隙と長い隙**を用意する。
- 通常攻撃で簡単には大きく怯まず、雑魚のようにまとめて吹き飛ばす対象にはしない。
- 攻撃パターン数は**2〜3種類を仮置き**。具体的なモーションや数値は未決定。
- 短い隙では弱→強、長い隙では弱→強→強の判断が生まれるよう調整する。
- 初期実装では雑魚召喚を入れない。
