# 戦闘仕様

状態: 操作・コンボ進行規則は**確定**。判定・フレーム数・演出強度は**未決定**。

## 基本アクション【確定】

| 操作 | 性質 | 主な用途 |
| --- | --- | --- |
| 弱攻撃 | 素早い広範囲攻撃。雑魚をリアの**前方の一点**へ寄せる（散らさない） | 集敵とコンボ始動 |
| 強攻撃（単発） | 広く横薙ぎする1撃。中程度の威力 | 手早い範囲制圧 |
| 弱 → 弱 → 強 | 弱で集敵し、広範囲・高威力の強で一掃 | 雑魚の集団殲滅 |
| 弱 → 強 → 強 | より狭い範囲に高い単体火力。最終強は前隙が長い | 対ボス |
| ステップ | 入力方向へ素早く短距離移動。ローリングではない | 回避・位置調整 |

- 「弱 → 強」でコンボを止められる。ボスの短い反撃機会に対応。
- ボスは基本的に集敵・通常の吹き飛びに強い耐性を持つ。
- ステップの距離、無敵時間、各攻撃の具体的な当たり判定は未決定。

## COMBO-001: 攻撃成立と進行【確定】

- **攻撃判定が出現した時点**で攻撃を実行済みとみなし、コンボが進む。空振りでも進む。
- 判定が出る前にステップでキャンセルした攻撃は**不発**。ダメージもコンボ進行も発生しない。
- すべての攻撃は**いつでもステップへキャンセル可能**。

## COMBO-002: ステップ挿入規則【確定】

- **各攻撃と次の攻撃の間にステップを1回だけ挟んでも、コンボは継続する**。
- 各**成立した攻撃**の後に「コンボを維持して使えるステップ1回」が補充される。
- ステップを**連続2回**行うとコンボ解除。回避操作そのものは禁止しない。
- 判定発生前にキャンセルした未成立攻撃は、コンボ進行もステップ権の補充も行わない。
- 攻撃間の時間切れでもコンボ解除するが、猶予時間は未決定。

### 例

- 継続: `弱 → STEP → 強 → STEP → 強`
- 解除: `弱 → STEP → STEP`
- 判定前キャンセル: `弱(判定前) → STEP` は弱攻撃が成立しない。
- `弱 → STEP → 強(判定前) → STEP` では強は成立せず、2回目のSTEPで継続権を消費し切っているためコンボは解除される。

## ATTACK-001: リスクは主に前隙で作る【確定】

通常: `前隙(短) → 攻撃判定 → 後隙`

対ボス用3段目の強: `前隙(長) ━━━ → 攻撃判定 → 後隙`

- 最終強は長めの**前隙（攻撃が出るまでの時間）**を持つ。過度に重い後隙で硬直させない。
- 前隙中でもステップキャンセルできるが、大技の判定が出る前ならその攻撃は捨てることになる。
- ボスの隙が短い場合は `弱 → 強` で切り上げ、長い場合は `弱 → 強 → 強` を狙う。
- 上記の長短は**相対的な方針**。フレーム数、派生受付時間、硬直時間は未決定。

## 手触りの検証【優先】

- 集敵方向と距離が直感的で、敵が1か所に集まって斬れるか。
- 強攻撃の広さ・ヒットリアクション・吹き飛びが気持ちよいか。
- 前隙によるリスクを理解でき、ステップキャンセルがストレスなく使えるか。
- ボスの短い/長い隙の違いが、コンボ選択につながるか。
